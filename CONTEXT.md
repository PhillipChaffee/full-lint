# full-lint

One folder per language — the strictest setup that stays usable. This glossary
holds the vocabulary of the repo's public face and its design decisions.

## Language

### The public face

**Landing README**:
The root `README.md` — the repo's public face and the only document the header
applies to.
_Avoid_: front page, home page

**Header**:
The centered opening block of the landing README: logo above a bare H1, then
description, badges, tagline, and nav links, all inside one centered block.
_Avoid_: banner, hero, masthead

**Logo**:
The repo's visual symbol: a shield carrying a checkmark on an emerald gradient
tile. Deliberately count-agnostic — it may not encode the number of language
folders, since more will be added.
_Avoid_: mark, icon, badge (a badge is a CI/shields status image)

**Social preview**:
The image GitHub shows when the repository link is shared on social platforms.
Uploaded by hand in repo Settings; GitHub stores it separately from the repo.
_Avoid_: OG image, link card
